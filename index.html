exsurge

A JavaScript library that renders Gregorian chant in square note notation, taking gabc as input and emitting SVG or canvas output.

  • Playback demo

    A rendered score you can hear: click any note to play from there. Speed, tuning (including historical A=415 and A=392), transposition, instrument and volume are all driven from host controls on the page, and a second score shows two independent players coexisting.

  • Rendering sandbox

    Paste gabc and watch it lay out as you type, in both the SVG and the canvas backend.

Both pages import src/index.js directly as native ES modules, so what you are looking at is this repository's current source rather than a built bundle.

Source, documentation and issues: github.com/vagdur/exsurge. This is a fork of bbloomf/exsurge, itself a fork of frmatthew/exsurge by Fr. Matthew Spencer, O.S.J.
